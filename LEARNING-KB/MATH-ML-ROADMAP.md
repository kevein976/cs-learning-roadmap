# 数学与机器学习路线

## 数学四层

1. 微积分：极限、导数、积分、偏导、梯度。
2. 线性代数：向量、矩阵、线性变换、特征值、最小二乘。
3. 概率统计：随机变量、分布、期望、方差、条件概率、估计与检验。
4. 优化：凸性、梯度下降、正则化、约束与数值稳定性。

每个主题都要完成“概念解释 + 手算题 + Python 验证 + 一页总结”。

## 机器学习顺序

- 数据划分、数据泄漏、基线和指标。
- 线性/逻辑回归、KNN、树模型、集成方法。
- 聚类、降维、异常检测。
- 时间序列、工况变化、缺失和噪声。
- 神经网络、PyTorch、表示学习。
- 不确定性、校准、可解释性和严谨实验。

## 研究级验收

能够解释为什么选择一个指标；说明训练/验证/测试如何按时间或工况隔离；报告均值、波动和失败案例；用固定随机种子重跑；不把相关性写成因果性。
