## 使用规则

- 每项学习都要有可检查的产出：代码、错题、实验记录、口语录音或一页总结。
- 优先保住校内成绩；考试周自动降低科研和额外课程负荷。
- 任何研究结论都要写清楚数据来源、许可、验证范围和局限。
- 不记录身份证号、住址、账号密钥、车辆识别码或其他敏感隐私。
- 每周只更新一份复盘，避免把收藏链接当成学习进度。
