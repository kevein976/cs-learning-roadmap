# Mac 零基础 Python

目标是 10 周后能独立写小程序、处理 CSV、画图并训练一个可解释的基线模型。

## 第 0 步：环境

- 确认 Mac 芯片和系统版本。
- 安装官方 Python 3.11 或学校/项目要求的版本。
- 建立一个独立虚拟环境，学会在终端进入和退出。
- 用编辑器打开项目，运行一个打印和一个读取文件的程序。
- 不把 API 密钥、车辆识别信息或私人数据放进仓库。

## 十周路线

| 周次 | 主题 | 小项目 | 验收 |
| --- | --- | --- | --- |
| 1 | 变量、类型、输入输出 | 单位转换器 | 能解释每个变量类型 |
| 2 | 条件与循环 | 转速区间分类 | 处理边界值 |
| 3 | 列表、字典、字符串 | 多组数据统计 | 写出 5 个测试样例 |
| 4 | 函数与模块 | 数据清洗函数 | 函数有输入/输出说明 |
| 5 | 文件与 CSV | 传感器数据汇总 | 找出缺失值与异常行 |
| 6 | 异常处理与调试 | 命令行记录器 | 能定位一个故意错误 |
| 7 | NumPy/Pandas | 表格分析 | 复现一张统计表 |
| 8 | Matplotlib | 时序曲线图 | 图有单位、标题、图例 |
| 9 | scikit-learn | 分类基线 | 正确切分训练/测试 |
| 10 | 综合项目 | 发动机遥测小报告 | README、结果、局限齐全 |

## 练习规则

先手写思路，再写代码；每次提交包含运行方法和一个失败案例。不会的 API 查官方文档并记录一句自己的解释。
