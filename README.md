# CS 学习路线与记录

这是我的计算机基础、编程、数据结构、Web、数据库与 AI 学习记录。

## 当前目标

- 补齐 C 语言、指针、内存和调试基础
- 用 C 实现数据结构与经典算法
- 掌握 C++ STL、面向对象和基础工程工具
- 用 Python、数学和机器学习为 CS/AI 硕士做准备
- 完成一个可展示的燃气专业动态管理系统

## 每周学习安排

每周投入约 25 小时：编程 10 小时，数学和专业课 5 小时，Web/数据库项目 5 小时，算法题 3 小时，复盘和英语阅读 2 小时。

### 第 1 周：C 基础和开发环境

- 任务：变量、类型、输入输出、分支、循环、函数；安装编译器和 VS Code；学会 Git commit。
- 产出：计算器、成绩统计、九九乘法表、10 次规范提交。
- 资源： [CS50 C 课程](https://github.com/cs50) · [C 语言练习](https://github.com/TheAlgorithms/C)

### 第 2 周：数组、字符串和指针入门

- 任务：数组、字符串、指针、函数参数、调试器。
- 产出：字符串反转、统计单词、冒泡排序、二分查找。
- 资源： [TheAlgorithms/C](https://github.com/TheAlgorithms/C) · [CS50 练习代码](https://github.com/cs50)

### 第 3 周：结构体和动态内存

- 任务：结构体、指针与结构体、malloc/free、文件读写。
- 产出：命令行通讯录，支持新增、删除、查找和保存。
- 资源： [CS-Basic-SelfLearning](https://github.com/LamberttLiu/CS-Basic-SelfLearning) · [CMake 教程](https://github.com/ttroy50/cmake-examples)

### 第 4 周：线性表和链表

- 任务：顺序表、单链表、双链表；分析时间复杂度。
- 产出：自己实现链表库，并为每个接口写测试。
- 资源： [practical-dsa](https://github.com/namphuongtran/practical-dsa) · [数据结构 C 实现](https://github.com/LamberttLiu/CS-Basic-SelfLearning)

### 第 5 周：栈、队列和递归

- 任务：栈、队列、循环队列、递归、括号匹配、表达式求值。
- 产出：迷宫求解或简单计算器。
- 资源： [TheAlgorithms/C](https://github.com/TheAlgorithms/C) · [Coding Interview University](https://github.com/jwasham/coding-interview-university)

### 第 6 周：树、堆和排序

- 任务：二叉树遍历、二叉搜索树、堆、快速排序、归并排序。
- 产出：排序算法对比报告，记录时间复杂度和实测结果。
- 资源： [TheAlgorithms/C-Plus-Plus](https://github.com/TheAlgorithms/C-Plus-Plus) · [数据结构与算法路线](https://github.com/ossu/computer-science)

### 第 7 周：图和经典算法

- 任务：邻接表、BFS、DFS、最短路径、并查集。
- 产出：校园路线查询或燃气管网连通性分析小程序。
- 资源： [TheAlgorithms/C](https://github.com/TheAlgorithms/C) · [算法学习清单](https://github.com/jwasham/coding-interview-university)

### 第 8 周：SQL 和数据库设计

- 任务：表设计、主键外键、JOIN、索引、事务、范式。
- 产出：为燃气系统完成数据库 ER 图和 10 张核心表，写 20 条 SQL。
- 资源： [learn-database](https://github.com/labex-labs/learn-database) · [数据库课程资料](https://github.com/ossu/computer-science)

### 第 9 周：HTML、CSS、JavaScript

- 任务：页面结构、布局、DOM、事件、表单、Fetch API。
- 产出：燃气设备台账页面和巡检记录页面。
- 资源： [Frontend Masters 学习路线](https://github.com/FrontendMasters/learning-roadmap) · [developer-roadmap](https://github.com/kamranahmedse/developer-roadmap)

### 第 10 周：前后端接口

- 任务：HTTP、REST API、登录、参数校验、错误处理。
- 产出：前端能读取和新增设备、巡检、隐患数据。
- 资源： [Full Stack Open](https://github.com/fullstack-hy2020/full-stack-open) · [Frontend Masters 路线](https://github.com/FrontendMasters/learning-roadmap)

### 第 11 周：项目工程化

- 任务：Git 分支、README、日志、测试、部署；整理代码结构。
- 产出：燃气动态管理系统第一个可运行版本。
- 资源： [Made With ML 工程实践](https://github.com/GokuMohandas/Made-With-ML) · [OSSU CS](https://github.com/ossu/computer-science)

### 第 12 周：复盘和 C++ 入门

- 任务：类、对象、引用、STL vector/string/map、用 C++ 重写 3 个数据结构。
- 产出：总结 12 周问题清单，整理 GitHub 项目展示页。
- 资源： [TheAlgorithms/C-Plus-Plus](https://github.com/TheAlgorithms/C-Plus-Plus) · [C++ Core Guidelines](https://github.com/isocpp/CppCoreGuidelines)

## 学习原则

1. 每周写代码并提交，少收藏，重实践。
2. 每个知识点都要有自己的实现、测试和总结。
3. 不复制答案；先独立完成，再对照资料改进。
4. 每周日复盘：本周完成、遇到的问题、下周计划。
