# cs-learning-roadmap

我的计算机基础、编程、数据结构、Web、数据库与 AI 学习记录。

## 当前目标

- 补齐 C 语言、指针、内存和调试基础
- 用 C 实现数据结构与经典算法
- 掌握 C++ STL、面向对象和基础工程工具
- 用 Python、数学和机器学习为 CS/AI 硕士做准备
- 完成一个可展示的燃气专业动态管理系统

## 学习原则

1. 每周写代码并提交，少收藏，重实践。
2. 每个知识点都要有自己的实现、测试和总结。
3. 不复制答案；先独立完成，再对照资料改进。
4. 每周日复盘：本周完成、遇到的问题、下周计划。

## 第一阶段：现在至本学期结束

- [ ] C：数组、字符串、函数、指针、结构体、动态内存
- [ ] 数据结构：线性表、链表、栈、队列、树、堆、图
- [ ] 算法：排序、二分查找、递归、BFS、DFS、最短路
- [ ] 离散数学：逻辑、集合、关系、图论、组合
- [ ] SQL：表设计、查询、索引、事务
- [ ] Web：HTML、CSS、JavaScript、表单和接口
- [ ] 完成燃气动态管理系统第一个可运行版本

## 第二阶段：暑假

- [ ] C++：类、继承、STL、CMake、基础 Linux
- [ ] Python：语法、面向对象、NumPy、Pandas、Matplotlib
- [ ] 用 C++ 重写部分数据结构和算法

## 第三阶段：大三

- [ ] 线性代数、概率统计、微积分
- [ ] 机器学习：回归、分类、树模型、聚类
- [ ] 深度学习：PyTorch、CNN、Transformer
- [ ] 完成至少一个 AI 项目并写清楚实验记录
