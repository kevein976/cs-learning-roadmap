
# CS 学习路线与记录

这是我的计算机基础、编程、数据结构、Web、数据库与 AI 学习记录。下面优先使用中文资料；CS50 官方课程是英文，暂时只作为以后想挑战英文课程时的可选资料，不作为当前主线。

## 当前目标

- 补齐 C 语言、指针、内存和调试基础
- 用 C 实现数据结构与经典算法
- 掌握 C++ STL、面向对象和基础工程工具
- 用 Python、数学和机器学习为 CS/AI 硕士做准备
- 完成一个可展示的燃气专业动态管理系统

## 每周学习安排

每周投入约 25 小时：编程 10 小时，数学和专业课 5 小时，Web/数据库项目 5 小时，算法题 3 小时，复盘 2 小时。

### 第 1 周：C 基础

- 任务：变量、类型、输入输出、分支、循环、函数、编译运行。
- 产出：计算器、成绩统计、九九乘法表。
- 中文资源： [零基础 C 语言入门到进阶](https://github.com/superlxh02/c-study) · [Mdr C 语言教程](https://github.com/Mdr-C-Tutorial/C)

### 第 2 周：数组、字符串和指针

- 任务：数组、字符串、指针、函数参数、调试器。
- 产出：字符串反转、统计单词、冒泡排序、二分查找。
- 中文资源： [零基础 C 语言入门到进阶](https://github.com/superlxh02/c-study) · [C 语言中文社区](https://github.com/cyyzwsq/c_coding)

### 第 3 周：结构体和动态内存

- 任务：结构体、malloc/free、文件读写、多文件编译。
- 产出：命令行通讯录，支持新增、删除、查找和保存。
- 中文资源： [CS 基础自学](https://github.com/LamberttLiu/CS-Basic-SelfLearning) · [CMake 示例](https://github.com/ttroy50/cmake-examples)

### 第 4 周：线性表和链表

- 任务：顺序表、单链表、双链表、时间复杂度。
- 产出：自己实现链表库，并为接口写测试。
- 中文资源： [数据结构 C 语言习题与代码](https://github.com/hairrrrr/C-DataStructure) · [Hello 算法](https://github.com/krahets/hello-algo)

### 第 5 周：栈、队列和递归

- 任务：栈、队列、循环队列、递归、括号匹配、表达式求值。
- 产出：迷宫求解或简单计算器。
- 中文资源： [Hello 算法](https://github.com/krahets/hello-algo) · [C 语言数据结构样例](https://github.com/liubaowei666/data_structure_samples)

### 第 6 周：树、堆和排序

- 任务：二叉树、二叉搜索树、堆、快速排序、归并排序。
- 产出：排序算法对比报告，记录复杂度和实测结果。
- 中文资源： [Hello 算法](https://github.com/krahets/hello-algo) · [C/C++ 数据结构实现](https://github.com/FENGFENGL/DataStructures)

### 第 7 周：图和经典算法

- 任务：邻接表、BFS、DFS、最短路径、并查集。
- 产出：校园路线查询或燃气管网连通性分析程序。
- 中文资源： [Hello 算法](https://github.com/krahets/hello-algo) · [计算机专业系统学习资料](https://github.com/hfdfk/ComputerStudent)

### 第 8 周：SQL 和数据库设计

- 任务：表设计、主键外键、JOIN、索引、事务、范式。
- 产出：燃气系统 ER 图、核心表和 20 条 SQL。
- 中文资源： [Datawhale SQL 教程](https://github.com/datawhalechina/wonderful-sql) · [MySQL 教程](https://github.com/guobinhit/mysql-tutorial) · [数据库教程](https://github.com/dunwu/db-tutorial)

### 第 9 周：HTML、CSS、JavaScript

- 任务：页面结构、布局、DOM、事件、表单、Fetch API。
- 产出：燃气设备台账页和巡检记录页。
- 中文资源： [前端学习路线](https://github.com/qianguyihao/Web) · [JavaScript 教程](https://github.com/javascript-tutorial/zh.javascript.info)

### 第 10 周：前后端接口

- 任务：HTTP、REST API、登录、参数校验、错误处理。
- 产出：前端能读取和新增设备、巡检、隐患数据。
- 中文资源： [前端学习路线](https://github.com/qianguyihao/Web) · [计算机专业系统学习资料](https://github.com/hfdfk/ComputerStudent)

### 第 11 周：项目工程化

- 任务：Git 分支、README、日志、测试、部署；整理代码结构。
- 产出：燃气动态管理系统第一个可运行版本。
- 中文资源： [计算机专业系统学习资料](https://github.com/hfdfk/ComputerStudent) · [中文编程资源导航](https://github.com/zieang88888/free-programming-books-zh)

### 第 12 周：C++ 入门和复盘

- 任务：类、对象、引用、STL vector/string/map，用 C++ 重写 3 个数据结构。
- 产出：总结问题清单，整理 GitHub 项目展示页。
- 中文资源： [C++ 入门路线与项目](https://github.com/Superone77/Cpp-basic-learning) · [信奥赛 C++ 自学站](https://github.com/xinaosai/xinaosai.github.io)

## 学习原则

1. 每周写代码并提交，少收藏，重实践。
2. 每个知识点都要有自己的实现、测试和总结。
3. 不复制答案；先独立完成，再对照资料改进。
4. 每周日复盘：本周完成、遇到的问题、下周计划。
