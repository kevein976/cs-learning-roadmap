## 优先级
1. **大学GPA与当期专业课**：先补数据结构、离散数学，争取数学及核心专业课高分。
2. **数学**：高中函数/代数薄弱处→微积分、线代→概率统计、离散数学→优化。
3. **编程**：Python入门用于AI；C补指针/内存；C++用于算法。不要同时从零刷三门。
4. **CS基础**：数据结构算法、计算机组成、操作系统、网络、数据库、软件工程、Linux/Git。
5. **AI**：NumPy→经典ML→PyTorch/深度学习→Transformer/NLP→研究复现。
6. **英语与科研**：每天英语；大二下联系导师，大三争取持续研究和强推荐信。

## 每周时间预算（课外约28–32小时，考试周优先校内课）
- 数学：9h；编程/数据结构：9h；英语：6h；课程作业/复盘：4h；AI探索：2–4h。
- 每周至少一天轻负荷，保证睡眠。AI探索在基础不足时可替换为补课。
- 每周日记录：学习小时数、做题正确率、代码提交、困难、下周调整。

## 验收原则
- 课程不是“看完”就算完成：必须做习题、独立写代码、闭卷自测。
- 项目保留README、复现步骤、基线、指标、误差分析、英文摘要。
- 申请信息每年核对CMU各项目官方网页，不将规划分数当作录取门槛。
