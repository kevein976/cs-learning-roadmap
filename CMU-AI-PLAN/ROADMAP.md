# 学期路线图（2026–2029）
> 日期按2026年11月大二上、2029年毕业估算；如学籍不同整体平移。

| 时间 | 重点 | 交付物/验收 |
|---|---|---|
| 2026.11–2027.01 大二上 | GPA、C基础、Python基础、微积分/线代、数据结构补课 | C链表/栈队列；Python小程序；数学自测 |
| 2027.02–06 大二下 | C++、数据结构算法、离散、概率；Git/Linux | 独立实现8类数据结构；40–60道分级算法题；导师名单 |
| 2027.07–08 暑假 | NumPy/Pandas、经典ML、PyTorch入门 | 手写回归与sklearn对照、英文报告 |
| 2027.09–2028.01 大三上 | 深度学习、系统基础、进入实验室 | 完成论文复现，保留实验日志与基线 |
| 2028.02–06 大三下 | NLP/Transformer或CV方向深入、研究 | 一份可复现实验报告；争取导师推荐 |
| 2028.07–08 暑假 | 研究/实习、英语考试、项目整理 | 项目英文README、成绩、简历初稿 |
| 2028.09–12 大四上 | 选校、核对要求、文书、推荐信、申请 | 按各项目截止日提交，保留备选学校 |
| 2029.01–毕业 | 补充材料、毕业设计、科研持续推进 | 稳住成绩、完成学位与入学准备 |

## 各学期硬性指标
- GPA：优先提高本校实际成绩，目标核心课85–90+（不是CMU官方录取线）。
- 数学：能闭卷解题并解释概念，薄弱章节二次学习。
- 代码：独立实现、测试、复杂度分析、Git提交。
- 科研：至少一次真实复现与持续导师指导；论文是加分项但不保证录取。
- 语言：雅思从6.0逐步提高，目标7.5；不同项目对单项/总分要求不同。
- 申请：CMU MSML、MSAII、相关AI工程方向分别核对课程定位、先修课、英语、GRE、截止日；同时准备其他学校梯度申请。
